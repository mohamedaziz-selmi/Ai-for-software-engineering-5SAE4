## 1. Context and objectives

Logistika Express wants a parcel tracking dashboard. The objective is to replace manual handling of parcels and reduce errors.

## 2. Parties

The client is Logistika Express. The client's project contact address is pm.raftp008@example.com, and the phone number for urgent issues is +216 90 596 916. The freelancer designs, builds, tests and deploys the application.

## 3. Scope

### 3.1 In scope

- Users can let drivers update parcel status from a phone browser.
- Users can show a daily delivery performance report.
- Users can import parcels from a CSV file.
- Users can assign parcels to delivery rounds.
- Users can notify customers by email when a parcel is out for delivery.

### 3.2 Out of scope

- Home delivery.
- A loyalty programme.
- Native mobile applications.

### 3.3 Change requests

Any feature that is not listed in section 3.1 is a change request. The freelancer sends an estimate within 3 business days, and work starts only after written approval by the client.

## 4. Non-negotiable requirements

- NN-1: The database is backed up every day and backups are kept for 14 days.
- NN-2: Passwords are hashed with scrypt.
- NN-3: Personal data is stored only on servers located in the European Union.
- NN-4: Every administrator account uses two-factor authentication.
