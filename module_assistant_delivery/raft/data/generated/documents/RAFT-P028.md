## 1. Context and objectives

Café Jasmin wants a table reservation website. The objective is to replace manual handling of table reservations and reduce errors.

## 2. Parties

The client is Café Jasmin. The client's project contact address is pm.raftp028@example.com, and the phone number for urgent issues is +216 87 142 377. The freelancer designs, builds, tests and deploys the application.

## 3. Scope

### 3.1 In scope

- Users can choose a date, time and party size.
- Users can cancel a reservation from the confirmation link.
- Users can manage opening hours and closed days.
- Users can receive an SMS confirmation.
- Users can let staff see tonight's reservations by table.

### 3.2 Out of scope

- Home delivery.
- Native mobile applications.
- Migration of historical data.

### 3.3 Change requests

Any feature that is not listed in section 3.1 is a change request. The freelancer sends an estimate within 2 business days, and work starts only after written approval by the client.

## 4. Non-negotiable requirements

- NN-1: Every administrator account uses two-factor authentication.
- NN-2: Personal data is stored only on servers located in Tunisia or the European Union.
- NN-3: Passwords are hashed with Argon2id.
- NN-4: Monthly availability is at least 99%.
