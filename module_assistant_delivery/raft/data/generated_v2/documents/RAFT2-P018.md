# Service agreement: a class booking web app for Studio Atlas Fitness

## 1. Context and objectives

Studio Atlas Fitness wants a class booking web app. The goal is to stop handling bookings by hand and reduce errors.

## 2. Parties and contacts

The client is Studio Atlas Fitness. Project questions go to pm.raft2p018@example.com; urgent issues can be reported by phone on +216 35 491 411. The freelancer designs, builds, tests and deploys the application.

## 3. Functional scope

### Included features

- Receive a reminder email 24 hours before a class.
- Let staff create and edit classes.
- Users can browse the weekly class timetable.
- Let coaches view their attendee list.
- Users can book and cancel a class.

### Out of scope

- A loyalty programme.
- Native mobile applications.
- Online card payment; customers pay on site.

## 4. Changes to the scope

Features not described above are handled as change requests. The freelancer sends an estimate within 3 business days, and work starts only after written approval by the client.

## 5. Essential requirements

- NN-1: Monthly availability is at least 99.5%.
- NN-2: The database is backed up every day and backups are kept for 7 days.
- NN-3: The home page reaches Largest Contentful Paint in under 2 seconds on a simulated 4G connection.
- NN-4: At most 15 bookings per class session.
