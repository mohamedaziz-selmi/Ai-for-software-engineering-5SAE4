# Contrat de prestation : une application de réservation de bureaux et salles de réunion pour CoWork Lac

Document d'entraînement synthétique RAFT2-P055. Le client, les personnes et les chiffres sont fictifs.

### Contexte

Aujourd'hui, CoWork Lac gère ses réservations avec des tableurs et des appels téléphoniques. Ce projet livre une application de réservation de bureaux et salles de réunion.

### Parties

Le client est CoWork Lac. L'adresse de contact projet du client est pm.raft2p055@example.com ; les urgences peuvent être signalées au +216 68 832 746. Le prestataire conçoit, développe, teste et déploie l'application.

### Périmètre fonctionnel

Le projet couvre les fonctionnalités suivantes : recevoir un récapitulatif mensuel d'utilisation par e-mail; s'enregistrer avec un code QR au bureau; permettre aux gestionnaires de définir des règles par formule; réserver un bureau ou une salle de réunion; voir un plan d'étage avec les bureaux libres.

Ne font pas partie du projet : la migration des données historiques; la tarification multi-devises; la livraison à domicile.

### Demandes de modification

Les fonctionnalités non décrites ci-dessus sont traitées comme des demandes de modification. Le prestataire envoie une estimation sous 2 jours ouvrables, et le travail ne commence qu’après accord écrit du client.

### Exigences non négociables

- La page d'accueil atteint un Largest Contentful Paint inférieur à 3 secondes sur une connexion 4G simulée.
- Les données personnelles sont hébergées uniquement sur des serveurs situés dans l'Union européenne.
- La base de données est sauvegardée chaque jour et les sauvegardes sont conservées 30 jours.
- La disponibilité mensuelle est d'au moins 99,9 %.
