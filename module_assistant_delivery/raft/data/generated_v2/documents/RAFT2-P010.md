# Project brief - Studio Atlas Fitness

## 1. Purpose of the project

Studio Atlas Fitness wants a class booking web app. The goal is to stop handling bookings by hand and reduce errors.

## 2. Parties and contacts

The client is Studio Atlas Fitness. Project questions go to pm.raft2p010@example.com; urgent issues can be reported by phone on +216 25 370 391. The freelancer designs, builds, tests and deploys the application.

## 3. Functional scope

### Included features

- Users can receive a reminder email 24 hours before a class.
- Let coaches view their attendee list.
- Let staff create and edit classes.
- Book and cancel a class.
- Join a waiting list when a class is full.

### Excluded

- Multi-currency pricing.
- Online card payment; customers pay on site.
- A loyalty programme.

## 4. Changes to the scope

Any feature that is not listed in the scope is a change request. The freelancer sends an estimate within 5 business days, and work starts only after written approval by the client.

- NN-2: Personal data is stored only on servers located in Tunisia.
