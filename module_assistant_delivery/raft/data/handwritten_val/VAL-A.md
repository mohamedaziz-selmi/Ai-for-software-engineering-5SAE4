# Statement of Work: MarsaFresh Grocery Pickup

Reference SOW-MF-2026-03. Synthetic validation document, written by hand for RAFT run 2; all names and figures are fictional.

## Why this project

MarsaFresh runs two grocery stores in Monastir. More and more customers ask to order online and collect their shopping from a locker at the store entrance. This statement of work describes the web application the freelancer will build for that purpose.

## What will be built

The freelancer will build a responsive web application in which customers create an account, fill a basket from the store catalogue and pick a collection window. They pay at the locker or at the till. Store staff get a preparation screen that lists the baskets to prepare for each collection window, and they print a label for each bag.

Each store has 4 lockers in the first version. A collection window lasts 45 minutes, and a window is closed for new orders once 12 baskets are booked in it.

What we will not build in this phase: delivery to customers' homes, a mobile app for the app stores, and an integration with the stores' loyalty card. Online payment by card is also left for a later phase.

## Quality requirements

Customer pages must work on the last two versions of Chrome, Firefox and Safari. Customer data stays on servers located in Tunisia. Staff accounts sign in with a password and a one-time code sent by SMS.
